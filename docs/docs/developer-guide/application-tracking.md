# Application Tracking

## Overview

Application tracking helps users manage their job search pipeline.

## Status Pipeline

Submitted → Reviewing → Interview → Assessment → Offer → Accepted/Rejected

## Features

- Track application status
- Add notes and reminders
- View statistics
- Filter and search
- Manual application entry
