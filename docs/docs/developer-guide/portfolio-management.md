# Portfolio Management

## Overview

Portfolio management features allow users to build comprehensive professional profiles.

## Controllers

**Location**: `backend/src/controllers/portfolio.controller.ts`

## Features

### Basic Information
- Professional title, tagline, bio
- Contact information

### Projects
- CRUD operations
- Images and links
- Technologies used

### Skills
- Add/remove/update skills
- Proficiency levels (0-100)

### Work History
- Company, position, dates
- Responsibilities and achievements

### Certifications
- Name, issuer, dates
- Credential verification

### Achievements
- Awards, publications, speaking
