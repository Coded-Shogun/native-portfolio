# Work History

## Overview

Work history provides credibility and context for your experience. It shows career progression and verifies your professional background.

## Adding Work Experience

1. Go to **Portfolio Editor** → **Work History** tab
2. Click **"Add Experience"**
3. Fill in details:
   - **Company Name**
   - **Position/Title**
   - **Start Date** and **End Date** (or check "Current")
   - **Description** of responsibilities and achievements
   - **Technologies Used** (comma-separated)
4. Click **"Save"**

## Writing Effective Descriptions

### Use Action Verbs
- Built, Developed, Designed, Implemented, Led, Managed, Optimized, Architected

### Quantify Achievements
- "Increased performance by 40%"
- "Reduced costs by $50,000 annually"
- "Led team of 5 developers"
- "Managed $2M budget"

### Include Impact
Focus on results, not just responsibilities.

**Weak**: "Responsible for developing features"
**Strong**: "Developed 15+ features serving 100K users, increasing engagement by 35%"

## Example Entry

**Title**: Senior Full Stack Developer
**Company**: Tech Startup Inc.
**Duration**: Jan 2020 - Present
**Description**:
```
Led development of core platform features using React and Node.js,
serving 50,000+ active users. Architected microservices migration that
reduced server costs by 40% and improved response times by 60%.
Mentored 3 junior developers and established code review processes
that improved code quality scores from 6.5 to 8.9.
```
**Technologies**: React, Node.js, PostgreSQL, AWS, Docker, Kubernetes

## Best Practices

- Add **all relevant experience**, including internships
- Keep descriptions **concise** (2-4 sentences)
- **List newest first**
- Include **technologies used** for each role
- Update when you change jobs

## Impact on Job Matching

Work history contributes **20% to match score** through experience level alignment.
