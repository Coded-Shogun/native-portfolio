# Skills Management

## Overview

Skills are crucial for AI job matching. The algorithm uses your skills and proficiency levels to calculate match scores with job opportunities.

## Adding Skills

1. Go to **Portfolio Editor** → **Skills** tab
2. Click **"Add Skill"**
3. Enter skill name (e.g., "React", "Python", "AWS")
4. Set proficiency level (1-100)
5. Click **"Save"**

## Proficiency Levels Guide

- **0-25: Beginner** - Basic familiarity, learning phase
- **26-50: Intermediate** - Can work with guidance
- **51-75: Advanced** - Confident, independent work
- **76-90: Expert** - Can mentor others, deep knowledge
- **91-100: Master** - Industry expert, thought leader

## Skill Categories

### Technical Skills
- Programming languages (JavaScript, Python, Java)
- Frameworks (React, Django, Spring Boot)
- Tools (Git, Docker, Kubernetes)
- Databases (PostgreSQL, MongoDB, Redis)
- Cloud platforms (AWS, Azure, GCP)

### Soft Skills
- Communication
- Leadership
- Problem-solving
- Time management
- Teamwork

## Best Practices

- **Add 5-15 skills** for complete profile
- **Be honest** about proficiency levels
- **Include job-relevant skills** from target roles
- **Update regularly** as you improve
- **Match job descriptions** for better matching

## Impact on Job Matching

Skills account for **40% of match score**! More matching skills = higher scores.
