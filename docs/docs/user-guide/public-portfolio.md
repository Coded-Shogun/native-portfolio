# Public Portfolio

## Overview

Your public portfolio is your professional presence on Career Portfolio Manager. It's what recruiters and hiring managers see when they visit your unique URL.

## Accessing Your Public Portfolio

**View as Visitor:**
1. Copy your portfolio URL from dashboard
2. Open in incognito/private browser window
3. See exactly what recruiters see

**Direct Link:**
`https://career-portfolio-manager.com/portfolio/{your-username}`

## Portfolio Sections

### Header
- Your name
- Professional title
- Tagline
- Location
- Contact links (LinkedIn, GitHub, etc.)

### About Section
- Your bio
- Years of experience
- Key expertise

### Projects Showcase
- Featured projects (up to 3) prominently displayed
- All other projects in grid layout
- Project images, titles, descriptions
- Technologies used
- Live demo and GitHub links

### Skills
- Visual skill bars or tags
- Proficiency levels displayed
- Categorized (if applicable)

### Work Experience
- Timeline view
- Company, title, dates
- Key achievements
- Technologies used

### Certifications
- Certification badges
- Issuer and dates
- Verification links

### Achievements
- Notable accomplishments
- Awards and recognition
- Speaking and publications

### Contact
- Email (only visible to verified recruiters)
- Social links
- Location

## Customization Options

### Theme
Choose from:
- Light mode
- Dark mode
- Auto (follows system preference)

### Layout
Select layout style:
- Classic (traditional resume-style)

Drag and drop to reorder:
- Put strongest section first

## Privacy Considerations

### What's Public
- All portfolio content you've added
- Professional information
- Public projects only

### What's Private
- Email (only to verified recruiters)
- Career preferences
- Job applications
- Match scores
- Analytics data

### Control Visibility
- Make portfolio recruiter-only
- Hide specific sections
- Unpublish temporarily
