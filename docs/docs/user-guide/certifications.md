# Certifications

## Overview

Certifications validate your expertise and boost credibility with recruiters. They can increase match scores by 5-10%.

## Adding Certifications

1. Go to **Portfolio Editor** → **Certifications** tab
2. Click **"Add Certification"**
3. Fill in:
   - **Name** (e.g., "AWS Certified Solutions Architect")
   - **Issuer** (e.g., "Amazon Web Services")
   - **Issue Date**
   - **Expiry Date** (if applicable)
   - **Credential ID**
   - **Credential URL** (verification link)
4. Click **"Save"**

## Best Practices

- **Keep current** - renew before expiry
- **Add credential ID** for verification
- **Link to badge** when available
- **Priority relevant** certs for target roles
- Only include **recognized certifications**

## Impact on Job Matching

Certifications contribute **5% to match score** and significantly boost recruiter confidence.
